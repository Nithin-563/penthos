To add a new read-only API endpoint to an Express + Prisma project, follow these steps:

---

### **1. Inspect Existing Code**
- **Express Server**:  
  Check `server.js` or `index.js` (where the Express app is initialized) to identify where routes are registered. Look for a `routes/` directory (common pattern).
- **Prisma Schema**:  
  Open `prisma/schema.prisma` to confirm existing models and ensure the new endpoint doesn’t require new tables (if any).
- **Tests**:  
  Review test files in `test/integration/` or `test/unit/` to avoid breaking existing functionality.

---

### **2. Add the Route**
- **Create a Route File**:  
  In `routes/api/`, create a new file (e.g., `users.js`) for the new endpoint.  
  Example:  
  ```js
  const express = require('express');
  const prisma = require('./prisma'); // Assume this is configured

  const router = express.Router();

  router.get('/users', async (req, res) => {
    const users = await prisma.user.findMany();
    res.json(users);
  });

  module.exports = router;
  ```

- **Register the Route**:  
  Add the router to the Express app in `server.js` (e.g., `app.use('/api', require('./routes/api/users'));`).

---

### **3. Update Prisma Schema (if needed)**
- If the endpoint requires a new table (e.g., `User`), add it to `prisma/schema.prisma`:  
  ```prisma
  model User {
    id Int @id @default(autoincrement)
    name String
    email String @unique
  }
  ```
- Run `npx prisma migrate dev --name add-user` to apply the migration.

---

### **4. Write Tests**
- **Unit Test**:  
  Test the route logic in `test/unit/api/users.test.js`:  
  ```js
  const request = require('supertest');
  const app = require('./server');

  describe('GET /api/users', () => {
    it('returns all users', async () => {
      const res = await request(app).get('/api/users');
      expect(res.status).toBe(200);
      expect(res.body).toBeAnArray();
    });
  });
  ```

- **Integration Test**:  
  Verify the endpoint works with the database in `test/integration/api/users.test.js` using Supertest.

---

### **5. Verify in Isolated Sandbox**
1. **Local Setup**:  
   - Clone the repo and install dependencies (`npm install`).  
   - Apply migrations: `npx prisma migrate dev --name add-user`.  
   - Start the server: `node server.js`.  

2. **Test the Endpoint**:  
   - Run tests: `npx jest`.  
   - Manually test:  
     ```bash
     curl http://localhost:3000/api/users
     ```
     Ensure it returns the expected data (e.g., a list of users).

3. **Confirm Success**:  
   - All tests pass.  
   - The endpoint is accessible and returns correct data.  
   - No existing tests fail.  

---

### **Key Notes**
- **Security**: Ensure the endpoint is protected if needed (e.g., via middleware).  
- **Documentation**: Add the endpoint to API docs (e.g., Swagger) if applicable.  
- **Minimal Changes**: Avoid modifying existing routes or models unless required.  

This approach ensures the new endpoint is safe, tested, and integrates seamlessly with the existing system.
