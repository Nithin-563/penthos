Here's a TypeScript function to find the first duplicate in an array, along with its time and space complexity analysis.

### ✅ Final Code
```typescript
function firstDuplicate(arr: number[]): number {
    const seen = new Set<number>();
    for (const num of arr) {
        if (seen.has(num)) {
            return num;
        }
        seen.add(num);
    }
    return -1; // No duplicate found
}
```

---

### 📈 Time and Space Complexity

- **Time Complexity**: **O(n)**  
  We iterate through the array once, and each lookup in the `Set` is O(1) on average. This ensures linear time relative to the input size.

- **Space Complexity**: **O(n)**  
  In the worst case, the `Set` stores all unique elements before a duplicate is found. This results in O(n) space usage.

---

### 🧪 Example Usage
```typescript
console.log(firstDuplicate([1, 2, 3, 2, 4])); // Output: 2
console.log(firstDuplicate([1, 2, 3, 4, 5])); // Output: -1
console.log(firstDuplicate([3, 3, 4, 5]));    // Output: 3
```
